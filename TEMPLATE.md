# Usando este repositório como template

Este repositório pode ser usado como **GitHub Template**:

1. Clique em **Use this template** → **Create a new repository**.
2. Marque **Include all branches** se quiser (opcional).
3. Clone o novo repositório e siga o README.

## O que vem pronto
- Núcleo TypeScript + duas receitas (node-cron, nextjs-site).
- Dockerfiles e configs de deploy (Railway, Render, Fly, Vercel).
- CI (`.github/workflows/check.yml`) rodando typecheck, testes e build.
- Templates de issue/PR.

## Após criar a partir do template
- Substitua `seu-usuario`/`SEU-USUARIO-GITHUB` nos botões de deploy do README.
- Configure as variáveis de ambiente (veja `.env.example`).
- (Opcional) Ative o repositório como template nas Settings se for publicar.
